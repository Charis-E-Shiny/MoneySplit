# App screenshots

Capture screenshots from a running build on a supported Android device or emulator. Keep them representative of the current UI and use test data only.

## Suggested files

Save approved captures in this directory with these names:

- `onboarding.png`
- `dashboard.png`
- `group.png`
- `payment-approval.png`
- `savings.png`

When screenshots are available, embed the relevant images in the root README's **Screenshots** section.

## Privacy and quality checklist

- Use fabricated names, balances, invite codes, and transactions.
- Remove notifications, account identifiers, and other unrelated personal data.
- Capture at a consistent device size and use readable text.
- Re-capture screenshots after significant UI changes.
- Do not generate illustrative mockups and present them as screenshots of the app.
